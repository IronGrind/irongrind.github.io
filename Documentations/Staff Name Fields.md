Staff registration name fields — November 8, 2026

Create Staff Account now has separate First name (FN), Middle initial (MI, optional), and Last name (LN) inputs. First and last names are required. The middle initial accepts one letter with an optional period and is saved in uppercase with a period.

The form combines the fields into the existing full_name value, for example Glenerine M. Castro. Compound given names and surnames remain supported. No database columns or existing names were changed. The inputs stack on narrow screens.

JavaScript syntax and existing shared form/unique-ID checks passed. The website changes are local.
