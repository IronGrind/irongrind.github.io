# IronGrind Data Dictionary

## Purpose and Scope

This dictionary describes the eight application tables in the PostgreSQL `public` schema. It follows `supabase/schema.sql` and the schema-affecting migrations in `supabase/migrations/`; the live Supabase catalog is authoritative if an installation differs.

Each entity below has its own field table, matching the reference format. Length shows the declared character limit, numeric precision and scale, or fixed storage size where applicable; PostgreSQL `text` and `text[]` have no declared character limit, and `jsonb` has no fixed maximum length. Required fields, defaults, checks, and field purpose are noted in Description. Supabase-managed `auth.users` is external to these eight application tables; its UUID `id` is referenced by the application.

## Table 1: `profiles`

**Description:** Stores application-facing account details and the user's access role. Each profile uses the same identifier as its Supabase Auth account.

| Field Name | Field Type | Length | Key | Description |
| --- | --- | --- | --- | --- |
| `id` | `uuid` | 16 bytes | PK; FK `auth.users.id` | Required. Auth account identifier; deleting the Auth user cascades to this profile. |
| `email` | `text` | Unlimited | UNIQUE | Required. Account email synchronized from Supabase Auth. |
| `username` | `text` | Unlimited | UNIQUE | Optional. Application username; availability checks compare case-insensitively. |
| `full_name` | `text` | Unlimited | — | Required; defaults to `''`. Display name associated with the account. |
| `role` | `text` | Unlimited | CHECK | Required; defaults to `member`. Allowed values are `admin` and `member`. |
| `created_at` | `timestamptz` | 8 bytes | — | Required; defaults to `now()`. Profile creation time. |

## Table 2: `members`

| `application_id` | `uuid` | 16 bytes | FK `membership_applications.id`; indexed | Optional. Registration application associated with the member; deleting it sets this field to NULL. The index is not unique. |
| `full_name` | `text` | Unlimited | — | Required. Member's full name. |
| `email` | `text` | Unlimited | — | Optional. Member contact email, synchronized from Auth when linked. |
| `username` | `text` | Unlimited | — | Optional. Member's application username, when available. |
| `mobile` | `text` | Unlimited | — | Optional. Member contact number; profile updates validate Philippine mobile format. |
| `date_of_birth` | `date` | 4 bytes | — | Optional. Member's birth date. |
| `age` | `smallint` | 2 bytes | CHECK >= 0 | Optional. Member's age, which may be calculated during profile updates. |
| `sex` | `text` | Unlimited | — | Optional. Member-provided sex value. |
| `height` | `numeric` | Precision 7, scale 2 | — | Optional. Height measurement; the unit is stored separately. |
| `height_unit` | `text` | Unlimited | CHECK `cm`, `in`, `ft` | Optional. Unit for the height measurement. |
| `weight_kg` | `numeric` | Precision 7, scale 2 | — | Optional. Member weight in kilograms. |
| `emergency_contact` | `jsonb` | Variable | — | Required; defaults to `{}`. Structured emergency-contact details. |
| `plan` | `text` | Unlimited | — | Optional. Current membership plan name. |
| `plan_price` | `numeric` | Precision 12, scale 2 | CHECK >= 0 | Required; defaults to `0`. Current membership price. |
| `start_date` | `date` | 4 bytes | — | Optional. Start date of the current membership period. |
| `expiry_date` | `date` | 4 bytes | — | Optional. Canonical membership expiry date. |

| `status` | `text` | Unlimited | CHECK `active`, `expired`, `inactive` | Required; defaults to `active`. Current member/membership status. |

| `paid` | `boolean` | 1 byte | — | Required; defaults to `false`. Whether payment is recorded as paid. |

| `other_medical_conditions` | `text` | Unlimited | — | Required; defaults to `''`. Additional medical information. |
| `signature_path` | `text` | Unlimited | — | Optional. Storage path or reference for the signature asset. |
| `created_at` | `timestamptz` | 8 bytes | — | Required; defaults to `now()`. Member record creation time. |
| `updated_at` | `timestamptz` | 8 bytes | — | Required; defaults to `now()`. Most recent member record update time. |

## Table 4: `attendance`

**Description:** Stores one record for each member visit to the gym. Check-in and optional check-out timestamps support attendance history and visit tracking.

| Field Name | Field Type | Length | Key | Description |
| --- | --- | --- | --- | --- |
| `id` | `uuid` | 16 bytes | PK | Required; generated by `gen_random_uuid()`. Attendance record identifier. |
| `member_id` | `uuid` | 16 bytes | FK `members.id`; indexed with `time_in` | Required. Member who attended; ON DELETE RESTRICT prevents deleting a referenced member. |
| `time_in` | `timestamptz` | 8 bytes | Part of `(member_id, time_in DESC)` index | Required; defaults to `now()`. Member check-in time. |
| `time_out` | `timestamptz` | 8 bytes | CHECK NULL or >= `time_in` | Optional. Member check-out time; NULL can indicate an open visit or missing check-out. |
| `recorded_by` | `uuid` | 16 bytes | FK `auth.users.id` | Optional. Staff account that recorded attendance; deleting the Auth user sets this field to NULL. |
| `created_at` | `timestamptz` | 8 bytes | — | Required; defaults to `now()`. Attendance row creation time. |

## Table 5: `products`

**Description:** Stores products offered for sale, including prices, units, and inventory information. Active and archived product records support catalog management and sales history.

| Field Name | Field Type | Length | Key | Description |
| --- | --- | --- | --- | --- |
| `id` | `uuid` | 16 bytes | PK | Required; generated by `gen_random_uuid()`. Product identifier. |
| `name` | `text` | Unlimited | — | Required. Product display name. |
| `category` | `text` | Unlimited | CHECK `supplement`, `merchandise` | Required. Product type and inventory behavior. |
| `price_per_unit` | `numeric` | Precision 12, scale 2 | CHECK >= 0 | Required. Price for one gram or item. |
| `unit` | `text` | Unlimited | CHECK `gram`, `item`; category consistency | Required. Supplements use `gram`; merchandise uses `item`. |
| `size` | `text` | Unlimited | — | Optional. Product size or package description. |
| `stock` | `integer` | 4 bytes | CHECK NULL or >= 0 | Optional. Merchandise quantity in stock; supplements use NULL. Sales operations expect stock to be set for merchandise. |
| `image_path` | `text` | Unlimited | — | Optional. Storage path or reference for the product image. |
| `is_active` | `boolean` | 1 byte | — | Required; defaults to `true`. Indicates whether the product is offered for sale. |
| `archived_at` | `timestamptz` | 8 bytes | — | Optional. Time the product was archived; added by `operational_data.sql`. |
| `created_at` | `timestamptz` | 8 bytes | — | Required; defaults to `now()`. Product creation time. |
| `updated_at` | `timestamptz` | 8 bytes | — | Required; defaults to `now()`. Most recent product update time. |

The category/unit/stock rule requires supplements to use `gram` with NULL stock and merchandise to use `item`. The merchandise inventory workflow expects its stock count to be populated.

## Table 6: `sales`

**Description:** Stores one record for each receipt-level transaction. It captures the customer, total, sale status, and staff account that processed the transaction.

| Field Name | Field Type | Length | Key | Description |
| --- | --- | --- | --- | --- |
| `id` | `uuid` | 16 bytes | PK | Required; generated by `gen_random_uuid()`. Sale identifier. |
| `receipt_number` | `text` | Unlimited | UNIQUE | Required. Human-readable receipt identifier. |
| `customer_type` | `text` | Unlimited | CHECK `member`, `walk_in` | Required. Identifies the customer category. |
| `customer_name` | `text` | Unlimited | — | Required. Customer name saved on the receipt. |
| `member_id` | `uuid` | 16 bytes | FK `members.id` | Optional. Member associated with the transaction; NULL for walk-in sales. ON DELETE SET NULL preserves the sale if the member record is removed. |
| `total` | `numeric` | Precision 12, scale 2 | CHECK >= 0 | Required. Total transaction amount. |
| `status` | `text` | Unlimited | CHECK | Required; defaults to `paid`. Canonical values are `paid` and `voided`; compatibility migrations normalize stored status text to lowercase. |
| `sold_at` | `timestamptz` | 8 bytes | Indexed descending | Required; defaults to `now()`. Time of sale. |
| `processed_by` | `uuid` | 16 bytes | FK `auth.users.id` | Optional. Staff account that processed the sale; deleting the Auth user sets this field to NULL. |

## Table 7: `sale_items`

**Description:** Stores each product or membership charge associated with a sale. Item name and price are retained as a transaction snapshot if the catalog record later changes or is removed.

| Field Name | Field Type | Length | Key | Description |
| --- | --- | --- | --- | --- |
| `id` | `uuid` | 16 bytes | PK | Required; generated by `gen_random_uuid()`. Sale-line identifier. |
| `sale_id` | `uuid` | 16 bytes | FK `sales.id`; indexed | Required. Parent receipt; ON DELETE CASCADE deletes its line items with the sale. |
| `product_id` | `uuid` | 16 bytes | FK `products.id` | Optional. Catalog product represented by this line; ON DELETE SET NULL preserves the sale-line snapshot. |
| `item_name` | `text` | Unlimited | — | Required. Item or plan name saved on the receipt. |
| `category` | `text` | Unlimited | CHECK `supplement`, `merchandise`, `membership` | Required. Type of item charged. |
| `quantity` | `numeric` | Precision 12, scale 3 | CHECK > 0 | Required. Quantity sold, including fractional gram amounts. |
| `unit` | `text` | Unlimited | CHECK `gram`, `item`, `membership` | Required. Unit used for the line quantity. |
| `unit_price` | `numeric` | Precision 12, scale 2 | CHECK >= 0 | Required. Price per unit at transaction time. |
| `line_total` | `numeric` | Precision 12, scale 2 | CHECK >= 0 | Required. Total price for this line. |

## Table 8: `membership_history`

**Description:** Stores membership lifecycle events and the relevant membership values before and after each event. These records support administrative review and reporting without replacing the member's current details.

| Field Name | Field Type | Length | Key | Description |
| --- | --- | --- | --- | --- |
| `id` | `uuid` | 16 bytes | PK | Required; generated by `gen_random_uuid()`. History event identifier. |
| `member_id` | `uuid` | 16 bytes | FK `members.id`; indexed with `recorded_at` | Required. Member whose membership changed; ON DELETE RESTRICT prevents deleting a member with history. |
| `event_type` | `text` | Unlimited | CHECK `expired`, `renewal`, `plan_change` | Required. Membership lifecycle event type. |
| `previous_plan` | `text` | Unlimited | — | Optional. Plan before the event. |
| `new_plan` | `text` | Unlimited | — | Optional. Plan after the event. |
| `previous_price` | `numeric` | Precision 12, scale 2 | CHECK NULL or >= 0 | Optional. Price before the event. |
| `new_price` | `numeric` | Precision 12, scale 2 | CHECK NULL or >= 0 | Optional. Price after the event. |
| `previous_start_date` | `date` | 4 bytes | — | Optional. Membership start date before the event. |
| `previous_expiry_date` | `date` | 4 bytes | — | Optional. Membership expiry date before the event. |
| `new_start_date` | `date` | 4 bytes | — | Optional. Membership start date after the event. |
| `new_expiry_date` | `date` | 4 bytes | — | Optional. Membership expiry date after the event. |
| `notes` | `text` | Unlimited | — | Required; defaults to `''`. Additional event context, such as a receipt reference. |
| `recorded_at` | `timestamptz` | 8 bytes | Part of `(member_id, recorded_at DESC)` index | Required; defaults to `now()`. Time the event was recorded. |
| `recorded_by` | `uuid` | 16 bytes | FK `auth.users.id` | Optional. Auth account that recorded the event; deleting the Auth user sets this field to NULL. |

## Relationships

| Relationship | Cardinality and delete behavior |
| --- | --- |
| `auth.users` to `profiles` | One-to-one by shared `id`; Auth user deletion cascades to its profile. |
| `auth.users` to `members` | Optional one-to-one; unique when `auth_user_id` is non-NULL. Auth user deletion clears the member link. |
| `auth.users` to `membership_applications` | One-to-many; Auth user deletion cascades to submitted applications. |
| `members` to `membership_applications` | One-to-many through `membership_applications.member_id`; member deletion clears this optional link. |
| `membership_applications` to `members` | Optional indexed origin link through `members.application_id`; not unique. Application deletion clears the member link. |
| `members` to `attendance` | One-to-many; attendance records restrict deletion of referenced members. |
| `members` to `sales` | One-to-many; member deletion clears the optional sale link. |
| `sales` to `sale_items` | One-to-many; sale deletion cascades to its line items. |
| `products` to `sale_items` | One-to-many; product deletion clears the product link while preserving the line snapshot. |
| `members` to `membership_history` | One-to-many; history records restrict deletion of referenced members. |
| Auth users to `recorded_by`, `reviewed_by`, `processed_by` | Optional attribution links; Auth user deletion clears the corresponding field. |

## Indexes

| Index | Fields | Purpose |
| --- | --- | --- |
| `members_auth_user_id_uidx` | `members(auth_user_id)` WHERE `auth_user_id IS NOT NULL` | Enforces at most one linked member per Auth user. |
| `members_application_id_idx` | `members(application_id)` | Finds a member from its originating application; not unique. |
| `applications_auth_user_id_idx` | `membership_applications(auth_user_id)` | Finds applications submitted by an account. |
| `applications_status_submitted_idx` | `membership_applications(status, submitted_at DESC)` | Supports application review queues. |
| `attendance_member_time_idx` | `attendance(member_id, time_in DESC)` | Retrieves a member's visits in time order. |
| `sales_sold_at_idx` | `sales(sold_at DESC)` | Supports recent sales and date-based reports. |
| `sale_items_sale_id_idx` | `sale_items(sale_id)` | Retrieves a receipt's line items. |
| `membership_history_member_date_idx` | `membership_history(member_id, recorded_at DESC)` | Retrieves a member's history in time order. |

`profiles.email`, `profiles.username`, and `sales.receipt_number` are unique in the canonical schema. Compatibility migrations may use partial unique indexes for nullable profile fields; `members.auth_user_id` is unique only when non-NULL.

## Access and Compatibility Notes

- Row-level security is enabled for all eight application tables. Members can access their own permitted records; administrators have broader management access as defined by the database policies.
- `expiry_date` is the canonical member expiry field; `end_date` remains for compatibility with membership operations.
- `emergency_contact` and `emergency_contact_data` coexist on applications for compatibility and are not automatically synchronized.
- Existing installations may retain legacy columns or have schema differences. Inspect the target project's PostgreSQL catalog and apply the documented migrations before making database changes.
